# অনুবাদ কাজ না করলে (v3.4)

**১. Settings → "🌐 অনুবাদ টেস্ট"** চাপুন। প্রতিটা সার্ভারের ফল দেখাবে:
`✅ google · 310ms · I am fine` অথবা `❌ google · 80ms · dns`

| কোড | মানে | করণীয় |
|---|---|---|
| `dns` / `connect` / `noroute` | ইন্টারনেট নেই বা অ্যাপের নেটওয়ার্ক বন্ধ | Wi-Fi/ডাটা দেখুন; ফোনের Settings → App → BanglaKeys → Network/Data usage-এ ব্যবহার অনুমতি; VPN/Private DNS/অ্যাড-ব্লকার (DNS) বন্ধ করে দেখুন |
| `timeout` | ধীর/আটকানো সংযোগ | আবার চেষ্টা; অন্য নেটওয়ার্কে দেখুন |
| `ssl` | তারিখ/সময় ভুল বা নেটওয়ার্ক HTTPS আটকাচ্ছে | ফোনের তারিখ-সময় "স্বয়ংক্রিয়" করুন |
| `429` / `quota` | ফ্রি সীমা শেষ | কিছুক্ষণ পরে; অন্য provider স্বয়ংক্রিয়ভাবে নেয় |
| `http403` / `http5xx` | সার্ভার ব্লক/বন্ধ | পরের provider নিজে চেষ্টা করে |
| `parse` | সার্ভার অন্য ধরনের উত্তর দিয়েছে (ক্যাপচা/HTML) | পরের provider |

সবকটা ❌ হলে কারণটা (বিশেষ করে `dns`) পাঠান — আসল সমস্যা সেখান থেকে ধরা যাবে।

**২. কিবোর্ডে অনুবাদ:** সিলেক্ট করা লেখা থাকলে সেটা; নইলে কার্সরের আগের পুরো লাইন (শেষ শব্দ নয়, পুরোটা)।
বাংলা থাকলে → English, নইলে → বাংলা। আবার চাপলে উল্টো দিকে ফেরে।
ব্যর্থ হলে Toast-এ কারণসহ বন্ধনীতে কোড আসে, যেমন `(google:dns)`।

**৩. কী ঠিক করা হয়েছে (v3.4):** আগে Bangla mode-এ শুধু চলতি শব্দ অনুবাদ হয়ে মূল শব্দের পাশে বসত
(প্রতিস্থাপন হত না), exception হলে অনুবাদ "আটকে" যেত, আর একটা সার্ভার বন্ধ থাকলে সবই বন্ধ ছিল।
